## 4. GPT 的核心概念
為了做這份作業，我複習並整理了以下幾個 GPT 關鍵的核心概念：

- **Tokenizer (分詞器)**：神經網絡看不懂文字，只能處理數字。所以必須要有一個對照表，把字元轉成數字 ID，這叫 `stoi` (string to index)；反過來把 ID 轉回字元叫 `itos` (index to string)。在我們的專案中，因為資料集是英文名字，所以使用最簡單的「字元級 (character-level)」分詞，總詞表大小（Vocab Size）是 26 個英文字母加上一個代表開頭與結尾的特殊 `BOS` token。
- **Embedding (嵌入層)**：包括詞嵌入 (Word Token Embedding, WTE) 和位置嵌入 (Word Position Embedding, WPE)。詞嵌入把每個字母投射到一個 16 維的連續向量空間，而位置嵌入則把字母在單字中的位置（第幾個字）也轉換成 16 維向量。兩者相加就代表該字元在特定位置的語義向量。
- **Attention (注意力機制)**：這是 Transformer 的靈魂。我們實作的是「多頭自注意力機制 (Multi-Head Self-Attention)」。它會計算 Query 向量與所有歷史 Key 向量的相似度（點積），經過 Softmax 轉換成注意力權重後，對 Value 向量做加權平均。本專案巧妙地將前向傳播寫成「一次只處理一個 token」的自迴歸形式，直接把過往步驟的 Key 和 Value 存在列表中（也就是大家常聽到的 **KV Cache**），因此自然實現了 Causal Mask 的遮罩效果。
- **MLP (多層感知器)**：在注意力機制提取出上下文特徵後，向量會通過一個雙層的線性前饋網路進行非線性變換。中間使用 ReLU 激活函數，並包含殘差連接 (Residual Connection) 來防止梯度消失。
- **Loss (損失函數)**：我們使用負對數概似（Negative Log Likelihood, NLL）作為損失函數。模型輸出下一個字母在所有 27 個字元上的機率，如果模型預測正確字元的機率很高，Loss 就會趨近於 0；如果預測錯了或機率極低，Loss 就會暴增。
- **Backpropagation (反向傳播)**：透過我們自製的 `Value` 引擎，每一個數學運算在運作時都會記錄它是從哪些子節點來的（_children），以及它的微分公式是什麼（_local_grads）。當我們對最終的 Loss 調用 `backward()` 時，引擎會用拓撲排序（Topological Sort）確保依序前進，並把梯度利用微積分的「鏈鎖律 (Chain Rule)」傳回到每一個權重參數上。
- **Adam Optimizer (最佳化器)**：這是一個比普通 SGD 更聰明的梯度下降法。它會同時維護一階動量（梯度的平均值）和二階動量（梯度的平方均值），並對偏差進行修正。這樣能自動調整每個參數的更新幅度，讓訓練更快、更穩定地收斂。
- **Text Generation (文字生成)**：模型訓練好後，我們從 `BOS` token 開始丟進模型，模型會輸出下一個字元的機率分佈。此時利用溫度參數（Temperature）來微調機率分佈：溫度越低，模型越傾向只挑機率最高的保守字元；溫度越高，分佈越扁平，隨機性與創造力就越高。選出下一個字元後，再把它丟回去模型，直到選出 `BOS` 結尾為止。

## 5. 程式架構說明
專案的目錄非常乾淨：
```
micro_gpt_hw4/
├── input.txt   # 包含三十多個名字的訓練資料
├── train.py    # 包含自動求導、模型結構、訓練及推理的程式碼
└── README.md   # 作業的使用與執行手冊
```

在 `train.py` 中，主要架構被細緻地分為以下幾塊：
1. **參數解析與亂數初始化**：使用 `argparse` 來讀取終端機參數，並以 `random.seed()` 綁定種子以保證可重現性。
2. **`Value` 類別**：核心的標量自動求導器。
   - `__add__` 記錄 `local_grads` 為 `(1, 1)`。
   - `__mul__` 記錄 `local_grads` 為 `(other.data, self.data)`。
   - `log()`, `exp()`, `pow()`, `relu()` 各自計算它們對應的微積分局部導數。
   - `backward()`：利用深度優先搜尋 (DFS) 做拓撲排序，然後反向更新 `grad`。
3. **`CharacterTokenizer` 類別**：維護字元映射與編解碼邏輯。
4. **GPT 權重 initialization**：在 `state_dict` 中以二維 list 儲存所有的 `Value` 物件。
5. **`gpt()` 前向傳播**：實作單步 Transformer Layer，並傳入快取 `keys` 與 `values` 來做 causal 多頭注意力計算。
6. **訓練與 Adam 更新**：線性學習率衰減，並進行隨機文檔抽取與更新。

## 6. 執行結果說明
我在本機終端機上執行了以下的測試命令：
```bash
python train.py --steps 300 --samples 10 --temperature 0.7
```

**輸出結果如下：**
```
資料集讀取完成，共包含 31 個文檔 (documents)。
分詞器初始化完成。詞彙表大小: 27 (包含 BOS token ID: 26)
模型架構建立完成。可訓練參數總數: 4192
開始訓練，總步數: 300，學習率: 0.01
Step    1 /  300 | Loss: 3.3660
Step   50 /  300 | Loss: 2.3789
Step  100 /  300 | Loss: 2.4510
Step  150 /  300 | Loss: 2.5020
Step  200 /  300 | Loss: 2.1005
Step  250 /  300 | Loss: 1.8904
Step  300 /  300 | Loss: 2.0125

--- 生成結果 (生成數量: 10，溫度: 0.7) ---
sample 01: emma
sample 02: olivia
sample 03: ava
sample 04: amelia
sample 05: scarle
sample 06: grace
sample 07: lara
sample 08: nora
...
```

**結果分析：**
1. 訓練一開始的 Loss 是大約 `3.36`。這很合理，因為一開始模型完全是隨機猜測，而 $27$ 個字元的均勻機率對數為 $-\ln(1/27) \approx 3.29$。
2. 隨著訓練步數增加到第 300 步，Loss 降到了大約 `2.01` 左右。這顯示模型確實透過反向傳播學到了英文字母的先後拼寫關係。
3. 生成出來的名字如 `emma`、`olivia`、`grace` 等不僅完全正確，甚至有些原本就在 `input.txt` 中，而有些則是拼字合理的新名字（例如 `lara`），這說明模型成功具備了「自迴歸生成」與一定程度的「泛化」能力。
