# HW3: XOR 分類 — 多層感知器 (MLP)

使用自製的自動微分引擎實作多層感知器，解決 XOR 非線性分類問題。

## 檔案
- `hw3-xor-classify.py` — 完整實作（Value autograd + Neuron/Layer/MLP + 訓練）

XOR 不能用一條直線分開，所以它不是線性問題。
如果只用簡單線性模型，學不起來。
但是加上隱藏層和非線性激活函數之後，神經網路就可以學會 XOR。

我的程式主要有五個流程：

1. forward 正向傳播
2. loss 損失計算
3. backward 反向傳播
4. grad 梯度更新
5. 參數學習

第一步，forward。
我把輸入丟進神經網路，讓模型算出預測結果。
例如 XOR 的資料是：

0 xor 0 = 0
0 xor 1 = 1
1 xor 0 = 1
1 xor 1 = 0

因為我使用 tanh，輸出範圍是 -1 到 1，所以我把答案改成：

0 對應 -1
1 對應 1

第二步，loss。
我用預測值和正確答案的差距計算損失。
如果模型預測錯，loss 就會變大；如果模型越接近正確答案，loss 就會變小。

第三步，backward。
這一步會從 loss 往回計算每個參數的梯度。
也就是計算每個權重對錯誤的影響有多大。

第四步，grad 更新。
有了梯度之後，就可以調整權重。
更新方向是往讓 loss 變小的方向走。

第五步，參數學習。
經過很多次 epoch 之後，模型的權重會逐漸調整到可以正確分類 XOR。
